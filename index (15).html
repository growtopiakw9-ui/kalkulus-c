1. Limit

Limit menyatakan nilai yang didekati f(x) saat x mendekati suatu titik.

lim x→a (f+g) = lim f + lim g lim x→a c·f = c · lim f

Jika bentuknya 0/0, faktorkan atau sederhanakan dulu.

Contoh: lim x→3 (x²−9)/(x−3) = lim (x+3) = 6

lim x→0 sin x / x = 1 lim x→0 (1−cos x)/x² = 1/2 lim x→∞ (1 + 1/x)^x = e lim x→∞ 1/x = 0

Limit di tak hingga untuk pecahan polinom: bandingkan pangkat tertinggi pembilang dan penyebut. Contoh lim (2x²+1)/(x²−3) = 2/1 = 2.

2. Turunan: aturan dasar
d/dx c = 0 d/dx xⁿ = n·xⁿ⁻¹ d/dx sin x = cos x d/dx cos x = −sin x d/dx eˣ = eˣ d/dx ln x = 1/x

Contoh: f(x)=3x²+2x → f'(x)=6x+2

3. Turunan: aturan hasil kali, bagi, rantai
(u·v)' = u'v + uv' (u/v)' = (u'v − uv') / v² d/dx f(g(x)) = f'(g(x)) · g'(x)

(x² sin x)' = 2x sin x + x² cos x
((3x+1)⁴)' = 4(3x+1)³·3 = 12(3x+1)³
(e²ˣ)' = 2e²ˣ

Turunan implisit: turunkan kedua ruas terhadap x, ingat y' = dy/dx. Contoh x²+y²=25 → 2x + 2y·y' = 0 → y' = −x/y.

4. Aplikasi turunan

Titik kritis: selesaikan f'(x)=0. Uji turunan kedua: f''(x)>0 → minimum lokal, f''(x)<0 → maksimum lokal.

f(x)=x³−3x → f'=3x²−3=0 → x=±1. f''=6x, jadi x=1 minimum, x=−1 maksimum.

L'Hôpital: untuk bentuk 0/0 atau ∞/∞, lim f/g = lim f'/g'. Contoh lim x→0 (eˣ−1)/x = lim eˣ/1 = 1.

5. Integral tak tentu
∫ xⁿ dx = xⁿ⁺¹/(n+1) + C (n ≠ −1) ∫ cos x dx = sin x + C ∫ sin x dx = −cos x + C ∫ eˣ dx = eˣ + C ∫ 1/x dx = ln|x| + C

∫ (3x²+2x+1) dx = x³ + x² + x + C

6. Integral tentu & substitusi
∫ₐᵇ f dx = F(b) − F(a)

∫₀² x dx = [x²/2]₀² = 2
∫₀^π sin x dx = [−cos x]₀^π = 2
Luas di bawah y=x² dari 0 sampai 3 = [x³/3] = 9

Substitusi: pilih u = bagian dalam. ∫ 2x/(x²+1) dx, u=x²+1, du=2x dx → ln(x²+1)+C.

Parsial: ∫ u dv = uv − ∫ v du. Contoh ∫ x eˣ dx = x eˣ − eˣ + C = (x−1)eˣ + C.

MATERI

1. Limit: cara menghitungnya

Limit artinya: kalau x makin dekat ke suatu angka, f(x) makin dekat ke angka berapa? Kita hanya melihat "mendekati", bukan "sama dengan".

Cara menghitung, coba berurutan:

1) Masukkan angkanya langsung ke fungsi. 2) Kalau hasilnya {0|0}, faktorkan lalu coret. 3) Kalau ada akar dan hasilnya {0|0}, kalikan dengan sekawannya.

Contoh dari soal: lim[x→4] {√[x²+8]|x}

Langkah 1: masukkan x = 4 {√[16 + 8]|4} = {√24|4} Langkah 2: sederhanakan akarnya √24 = √[4·6] = 2√6 Langkah 3: sederhanakan pecahannya {2√6|4} = {√6|2} ≈ 1,22

Penyebutnya 4 (bukan 0), jadi langsung masuk saja sudah aman.

Contoh 0 per 0: lim[x→3] {x² − 9|x − 3}

Masuk x = 3 → {0|0}, belum bisa. Faktorkan: x² − 9 = (x − 3)(x + 3) {(x − 3)(x + 3)|x − 3} = x + 3 Masuk x = 3 → 3 + 3 = 6
lim[x→0] {sin x|x} = 1 lim[x→∞] {1|x} = 0 lim[x→∞] {2x² + 1|x² − 3} = {2|1} = 2

Untuk x menuju tak hingga: lihat pangkat x tertinggi di atas dan di bawah. Kalau pangkatnya sama, hasilnya perbandingan angka depannya.

2. Membuktikan limit & "seberapa dekat?"

Soal: buktikan lim[x→5] {x² − 25|x − 5} = 10

Langkah 1: coba masuk x = 5 → {0|0}. Belum bisa. Langkah 2: faktorkan x² − 25 = (x − 5)(x + 5) Langkah 3: coret (x − 5) {(x − 5)(x + 5)|x − 5} = x + 5 Langkah 4: masuk x = 5 → 5 + 5 = 10 ✔ terbukti

Kenapa boleh dicoret? Karena x hanya mendekati 5, tidak pernah tepat 5, jadi (x − 5) tidak nol.

Soal "seberapa dekat": f(x) = 4x². Seberapa dekat x ke 2 agar f(x) berada dalam 0,05 dari 16?

Dulu cek: f(2) = 4·4 = 16 Syarat: 16 − 0,05 < 4x² < 16 + 0,05 15,95 < 4x² < 16,05 3,9875 < x² < 4,0125 Akarkan: 1,99687 < x < 2,00312 Jarak ke 2: kiri = 2 − 1,99687 = 0,00313 kanan = 2,00312 − 2 = 0,00312 Ambil yang paling kecil → |x − 2| < 0,0031

Cara tebak cepat: kemiringan kurva di x = 2 adalah f′(2) = 16, jadi {0,05|16} ≈ 0,003. Hasilnya cocok.

Interpretasi: x harus sangat-sangat dekat dengan 2 (selisih kurang dari 0,0031). Kurvanya curam di sana, jadi geser x sedikit saja nilai f(x) sudah melenceng jauh.

Catatan: di soal di fotomu tertulis "12", tapi f(2) = 16. Cek lagi angkanya. Kalau memang 12, berarti x dekat √3 (bukan 2), dan caranya sama: selesaikan |4x² − 12| < 0,05.

3. Turunan dengan limit (definisi)

Turunan itu kemiringan kurva di satu titik. Rumus dasarnya:

f′(x) = lim[h→0] {f(x + h) − f(x)|h}

Langkah kerjanya selalu sama:

1) Tulis f(x + h) 2) Kurangkan dengan f(x) 3) Bagi dengan h (h-nya jadi bisa dicoret) 4) Baru masukkan h → 0

Contoh dari soal: f(x) = x³ + 7x

Ingat: (x + h)³ = x³ + 3x²h + 3xh² + h³ f(x + h) = (x + h)³ + 7(x + h) = x³ + 3x²h + 3xh² + h³ + 7x + 7h f(x + h) − f(x) = 3x²h + 3xh² + h³ + 7h Bagi h: {3x²h + 3xh² + h³ + 7h|h} = 3x² + 3xh + h² + 7 h → 0: f′(x) = 3x² + 7

Lalu nilai turunan di x = 4:

Dₓf(4) = 3·4² + 7 = 48 + 7 = 55

Contoh lain: f(x) = x³ + 8x → dengan cara yang sama hasilnya f′(x) = 3x² + 8.

4. Turunan langsung (cara cepat)
{d|dx} c = 0 {d|dx} xⁿ = n·xⁿ⁻¹ {d|dx} sin x = cos x {d|dx} cos x = −sin x {d|dx} eˣ = eˣ {d|dx} ln x = {1|x}
Hasil kali: (u·v)′ = u′v + uv′ Hasil bagi: ({u|v})′ = {u′v − uv′|v²} Aturan rantai: {d|dx} f(g(x)) = f′(g(x))·g′(x)

Cek soal tadi: f(x) = x³ + 8x → f′(x) = 3x² + 8. Sama dengan cara limit.

Tips: kalau x ada di bawah (penyebut), ubah dulu jadi pangkat negatif. {1|x} = x⁻¹ dan {1|x²} = x⁻².

Contoh: y = {2|x} − {1|x²}

Ubah dulu: y = 2x⁻¹ − x⁻² Turunkan: y′ = −2x⁻² + 2x⁻³ Kembalikan ke pecahan: y′ = −{2|x²} + {2|x³}

Contoh hasil bagi: y = {x cos x + sin x|x² + 1}

u = x cos x + sin x u′ = (cos x − x sin x) + cos x = 2cos x − x sin x v = x² + 1, v′ = 2x y′ = {u′v − uv′|v²} = {(2cos x − x sin x)(x² + 1) − 2x(x cos x + sin x)|(x² + 1)²} Buka kurung di atas: 2x²cos x + 2cos x − x³sin x − x sin x − 2x²cos x − 2x sin x = 2cos x − x³sin x − 3x sin x y′ = {2cos x − x(x² + 3) sin x|(x² + 1)²}

Contoh akar: y = √[x² + 8]

Rumus: kalau y = √[u], maka y′ = {u′|2√[u]} Di sini u = x² + 8 dan u′ = 2x y′ = {2x|2√[x² + 8]} = {x|√[x² + 8]}
5. Garis singgung

Garis singgung adalah garis yang menyentuh kurva di satu titik. Kemiringan (gradien) garis itu = turunan di titik tersebut.

m = f′(a) y − f(a) = m (x − a)
Langkah: 1) Cari titiknya: (a, f(a)) 2) Cari f′(x), lalu masukkan a → dapat m 3) Masukkan ke rumus y − f(a) = m(x − a)

Contoh: garis singgung f(x) = x³ + 7x di x = 1

f(1) = 1 + 7 = 8 → titik (1, 8) f′(x) = 3x² + 7 → m = f′(1) = 10 y − 8 = 10(x − 1) y = 10x − 2

Garis normal (tegak lurus garis singgung) punya gradien −{1|m}.

6. Membuat fungsi dari garis singgung

Idenya: informasi garis singgung dipakai untuk mencari rumus fungsinya. Ada dua petunjuk yang bisa kita pakai:

Petunjuk 1 (titik): kurva lewat (a, b) → f(a) = b Petunjuk 2 (gradien): garis singgung di x = a punya gradien m → f′(a) = m

Tipe A: gradien tiap titik f′(x) = 2x + 3, kurva lewat (1, 6). Cari f(x).

Kebalikan turunan (integral): f(x) = x² + 3x + C Masuk titik (1, 6): 1 + 3 + C = 6 → C = 2 f(x) = x² + 3x + 2

Tipe B: f(x) = ax² + bx, lewat (1, 3), gradien garis singgung di titik itu 4. Cari a dan b.

Dari titik: f(1) = a + b = 3 Dari gradien: f′(x) = 2ax + b → f′(1) = 2a + b = 4 Kurangkan dua persamaan: a = 1, lalu b = 2 f(x) = x² + 2x

Tipe C: garis y = 2x + 1 menyinggung kurva y = x² + c. Cari c.

Gradien sama: 2x = 2 → x = 1 Di x = 1 garis bernilai y = 2·1 + 1 = 3 Kurva juga harus 3: 1² + c = 3 → c = 2 Kurvanya y = x² + 2

Kuncinya: selalu ada dua syarat, nilai sama dan gradien sama.

7. Titik maksimum & minimum

Puncak bukit = maksimum, dasar lembah = minimum. Di puncak dan dasar, garis singgungnya datar, jadi turunannya 0.

1) Cari f′(x) 2) Selesaikan f′(x) = 0 → dapat titik kritis x 3) Uji dengan turunan kedua: f″(x) > 0 → minimum lokal f″(x) < 0 → maksimum lokal 4) Masukkan x ke f(x) untuk dapat nilai maks/min-nya

Contoh: f(x) = x³ − 3x

f′(x) = 3x² − 3 = 0 → x = 1 atau x = −1 f″(x) = 6x x = 1: f″ = 6 > 0 → minimum, f(1) = 1 − 3 = −2 x = −1: f″ = −6 < 0 → maksimum, f(−1) = −1 + 3 = 2

Pada interval tertutup, bandingkan titik kritis dan kedua ujung. Contoh: f(x) = x² − 4x + 3 pada [0, 5]

f′(x) = 2x − 4 = 0 → x = 2 f(2) = 4 − 8 + 3 = −1 f(0) = 3 f(5) = 25 − 20 + 3 = 8 Terkecil: −1 (di x = 2) → minimum Terbesar: 8 (di x = 5) → maksimum

Soal cerita: dua bilangan jumlahnya 20. Hasil kali terbesar?

Bilangan pertama x, kedua 20 − x P = x(20 − x) = 20x − x² P′ = 20 − 2x = 0 → x = 10 P″ = −2 < 0 → maksimum P = 10 · 10 = 100
8. Integral & jumlah Riemann
∫ xⁿ dx = {x^(n+1)|n + 1} + C (n ≠ −1) ∫ cos x dx = sin x + C ∫ sin x dx = −cos x + C ∫ eˣ dx = eˣ + C Integral tentu: ∫[a|b] f(x) dx = F(b) − F(a)

Soal: hitung ∫[−2|3] (x + 4) dx dengan dua cara (hasilnya harus sama)

Cara 1: integral langsung

F(x) = {x²|2} + 4x F(3) = {9|2} + 12 = {33|2} F(−2) = {4|2} − 8 = −6 Hasil = {33|2} − (−6) = {33|2} + 6 = {45|2} = 22,5

Cara 2: jumlah Riemann. Bagi daerah di bawah kurva jadi n persegi panjang tipis, jumlahkan luasnya, lalu biarkan n makin besar.

Lebar tiap persegi panjang: Δx = {3 − (−2)|n} = {5|n} Titik ke-i (ujung kanan): xᵢ = −2 + i·{5|n} = −2 + {5i|n} Tinggi: f(xᵢ) = xᵢ + 4 = 2 + {5i|n} Jumlah = Σ[i=1|n] (2 + {5i|n}) · {5|n} = Σ[i=1|n] {10|n} + Σ[i=1|n] {25i|n²} = {10|n}·n + {25|n²}·Σ[i=1|n] i

Pakai rumus: 1 + 2 + 3 + ⋯ + n = {n(n + 1)|2}

Jumlah = 10 + {25|n²} · {n(n + 1)|2} = 10 + {25(n + 1)|2n} Biarkan n → ∞, maka {n + 1|n} → 1: lim[n→∞] (10 + {25(n + 1)|2n}) = 10 + {25|2} = {45|2} = 22,5 ✔

Dua cara hasilnya sama: 22,5.
